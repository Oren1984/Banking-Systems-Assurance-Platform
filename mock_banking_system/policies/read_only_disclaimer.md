# Mock Bank — Synthetic Policy Document

**SYNTHETIC DEMONSTRATION CONTENT — not a real policy.**

This document exists only so the mock system has at least one plain-text policy artifact
alongside its source code, mirroring what a real assessment target would include. It contains
no real policy content — only the standing disclaimer every report generated by the Banking
Systems Assurance Platform already carries (see `reporting/assessment_report_exporter.py`):

- The platform is read-only toward every system it assesses. It never modifies, executes, or
  writes to a scanned target.
- Findings and recommendations are advisory only. The platform never applies a fix
  automatically.
- Illustrative technical controls evaluated by the platform are not a citation to any specific
  banking regulation or standard — see `knowledge_base/controls/README.md`.
- No finding, score, or recommendation in a platform report is generated by an AI/LLM/RAG
  component; all detection and scoring logic is deterministic.
